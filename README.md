## 📖 Overview

**AI for Climate Vision** is an interactive learning platform designed to empower students, researchers, developers, and climate enthusiasts with the knowledge and skills needed to apply **Artificial Intelligence (AI)** and **Computer Vision** to real-world environmental challenges.

The platform combines theoretical lessons, practical projects, and real-world datasets to help learners understand how emerging technologies can support climate action, biodiversity conservation, disaster response, and sustainable development.

---

## 🎯 Learning Objectives

By completing the courses, learners will be able to:

- Understand the fundamentals of Artificial Intelligence and Machine Learning.
- Apply Computer Vision techniques to environmental datasets.
- Analyze satellite imagery using AI models.
- Detect environmental changes and climate-related risks.
- Build AI-powered solutions for sustainability challenges.
- Interpret and communicate environmental insights effectively.

---

## 🌱 Course Modules

### Module 1: Introduction to AI for Climate Action

- What is Artificial Intelligence?
- Understanding climate change challenges
- AI applications for sustainability
- Ethical and responsible AI

### Module 2: Computer Vision Fundamentals

- Digital image processing
- Object detection techniques
- Image classification
- Convolutional Neural Networks (CNNs)
- Deep learning basics

### Module 3: Earth Observation and Remote Sensing

- Satellite imagery fundamentals
- Multi-spectral and hyperspectral data
- Vegetation indices (NDVI)
- Land use and land cover analysis

### Module 4: Climate Change Applications

- Deforestation detection
- Wildfire monitoring
- Waste and pollution identification
- Biodiversity and ecosystem monitoring
- Disaster impact assessment

### Module 5: Capstone Project

- Problem definition
- Dataset preparation
- Model development
- Deployment and presentation
- Impact evaluation

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/ai-climate-vision.git
```

### Navigate to the project directory

```bash
cd ai-climate-vision
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the environment

**Windows**

```bash
venv\Scripts\activate
```

**macOS/Linux**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run app.py
```
